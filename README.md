## ✨ What is Cadence Studio?

Cadence Studio is a **real-time AI communication training system** — not a content generator, but a genuine coach that makes *you* a better communicator.

Every piece of feedback is **strictly grounded in your actual spoken transcript**. No fabricated scores. No generic advice. The AI coach listens to what you actually said, then gives you targeted, high-leverage improvements.

## ⚡ Key Features

### 🎯 Real-Time Live Analytics
- **Live WPM** — speech pace calculated dynamically as you speak
- **Filler Word Detection** — `um`, `uh`, `like`, `basically`, `you know` tracked per word
- **Pause Gap Timer** — detects silence gaps > 1.5s with count
- **Mic Energy Level** — real-time vocal signal strength indicator

### 📝 Live Transcript — All Modes
- Streaming interim text appears word-by-word as you speak
- Persistent transcript panel visible in every mode
- Color-coded by speaker (You / Coach)

### 💼 Dynamic Interview Questions
- Questions generated by Gemini AI based on your **track + role + difficulty**
- **Behavioral** → STAR-method questions on past experiences
- **HR** → Cultural fit, career goals, motivations
- **Technical** → Role-appropriate system design / problem-solving
- **Leadership** → Strategic influence, organizational impact

### ⌨️ Text Input Mode
- Don't want to speak? Switch to text input in any mode
- Type your response — Gemini analyzes it identically to spoken speech

### 📊 Post-Session Dashboard
- Overall score ring with data-grounded metrics
- Top 3 high-leverage improvements with Before/After examples
- Best moment & weakest moment quotes from your transcript
- Filler word breakdown
- Recommended practice drill

### 📄 Downloadable Reports
- **PDF Report** — full formatted session report with all scores and feedback
- **JSON Export** — structured data for your own analysis

### 📅 Session History
- Persistent local history of past sessions
- View, re-analyze, or delete past sessions

## 🛠️ Tech Stack

### Frontend
- **React 18** — component-based UI
- **Vite** — lightning-fast build tool
- **Vanilla CSS** — glassmorphism design system with custom animations
- **Web Speech API** — browser-native speech recognition with auto-restart
- **Web Audio API** — real-time mic energy level via AnalyserNode
- **jsPDF + html2canvas** — client-side PDF report generation

### Backend
- **Node.js + Express** — REST API server
- **Google Gemini 2.0 Flash** — AI analysis engine (`@google/generative-ai`)
- **Netlify Functions** — serverless backend deployment

### Deployment
- **Netlify** — frontend + serverless functions

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- A [Google Gemini API key](https://aistudio.google.com/app/apikey)

### 1. Clone the repo
```bash
git clone https://github.com/deveshratna/ai-communication-coach.git
cd ai-communication-coach
```

### 2. Install dependencies
```bash
# Backend
npm install

# Frontend
cd client && npm install && cd ..
```

### 3. Configure environment
```bash
cp .env.example .env
```
Edit `.env`:
```env
PORT=5000
GEMINI_API_KEY=your_gemini_api_key_here
```

### 4. Run locally
```bash
# Backend (in root)
npm run dev

# Frontend (in /client)
cd client && npm run dev
```

Frontend → `http://localhost:5173`  
Backend → `http://localhost:5000`

## 🌐 Deploying to Netlify

### Option A — Auto-deploy from GitHub (Recommended)
1. Push this repo to GitHub
2. Go to [app.netlify.com](https://app.netlify.com) → **Add new site → Import from Git**
3. Connect your GitHub repo
4. Set **Build command**: `npm run build`
5. Set **Publish directory**: `client/dist`
6. Add environment variable: `GEMINI_API_KEY` = your key
7. Deploy!

### Option B — Manual deploy
```bash
npm run build
npx netlify-cli deploy --prod --dir=client/dist
```

## 🎨 Design System

Cadence Studio uses a custom dark-mode glassmorphism design:

- **Colors**: Cyan `#22d3ee` + Purple `#8b5cf6` dual-accent system
- **Typography**: Space Grotesk (display) + Inter (body)
- **Glass**: Multi-layer `backdrop-filter: blur(20px) saturate(150%)`
- **Animations**: Spring-eased transitions, `pulseGlow`, `slideUp`, `borderGlow`
- **Shadows**: Layered with accent color glow effects
